# Breez SDK - Liquid

## Notice for Builders

For new partners looking to add instant, non-custodial bitcoin and stablecoins to their apps or services, we recommend building with the [Breez SDK - Spark](https://sdk-doc-spark.breez.technology/).

For existing partners building with the Breez SDK - Liquid, we recommend moving to the [Spark implementation](https://sdk-doc-spark.breez.technology/) as soon as possible.
